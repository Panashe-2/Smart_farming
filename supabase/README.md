# Smart Farming – Supabase Database

## Overview
This folder contains the Supabase PostgreSQL database implementation for the Smart Farming project.

## Database Tables
- farm_zones
- sensor_readings
- predictions
- crop_records
- alerts

## Database Features
- PostgreSQL database hosted on Supabase.
- Row Level Security (RLS).
- Database relationships.
- Data storage for smart farming operations.

## Architecture
React Frontend → Django Backend → Supabase PostgreSQL

## Database Management
Database schema, migrations, security policies and setup documentation are maintained in this folder.
